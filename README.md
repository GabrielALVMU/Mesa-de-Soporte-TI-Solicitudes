# Mesa de Soporte TI – MVP v1.0

## Tecnologías
- Frontend: React 18 + Vite
- Backend: Node.js + Express
- Base de datos: SQLite

## Ejecución
Abre dos terminales.

**Terminal 1 – API (puerto 3001)**
```bash
cd server
npm install
npm start
```

**Terminal 2 – Frontend (puerto 5173)**
```bash
cd client
npm install
npm run dev
```

Abre http://localhost:5173
